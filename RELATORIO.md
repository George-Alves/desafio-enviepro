# Relatório do Desafio EnviePro

## 1. Como organizei o tempo

Não cheguei a organizar o tempo. Eu queria testar a capacidade da IA, então coloquei ela para analisar o desafio e o modelo de projeto e para iniciar o planejamento.

## 2. Quais IAs usei e para quê

Usei apenas o Claude, na versão Claude Code desktop, com o modelo Sonnet 5.5.

## 3. As 3 decisões mais importantes

A decisão mais importante foi orientar a IA a seguir o desafio.

## 4. O que deu errado

Nunca tinha usado o Cursor como IDE e tive problemas no terminal para rodar os comandos do Node. Travei nisso e resolvi seguir por outro terminal.

## 5. O que não entendi

Por que fazer o projeto sem o CRUD? A ideia era testar apenas a forma como eu uso a IA?

## 6. Como testei

Pela orientação que passei para o Claude e acompanhando os merges no GitHub.

## 7. O que faria diferente

O desafio não pede um mock do projeto. Eu faria um antes de começar a codar e adicionaria uma etapa para incluir um CRUD no CRM, para ver o funcionamento dele com um usuário ativo.
